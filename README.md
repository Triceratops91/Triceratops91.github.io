# Dai-An Li

Personal academic website of Dai-An Li 李岱安.

## GitHub Pages

Publish the `main` branch from the repository root (`/`) in Settings → Pages.

## Updating content

- `script.js`: page content and interactions
- `styles.css`: visual styles and layout
- `index.html`: document metadata and application entry point
- `assets/`: photographs, videos, logos, and fonts

Keep asset paths relative. This website uses hash-based navigation and needs no build step.
